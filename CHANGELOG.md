## [1.0.0] - Unreleased

### Added

- Shared adaptive Android, iOS, Desktop, and Web workspace for local-first AI conversations.
- Ollama, OpenAI-compatible, Android Gemini Nano, and Apple Foundation Models provider integrations where supported.
- Local native chat history, session-only Web storage, streaming responses, cancellation, Harness prompts, and constrained Desktop tool execution.
- Deterministic store metadata and screenshot pipelines for Google Play and the App Store.
- Protected production workflows for Google Play, App Store Connect, GitHub Releases, and GitHub Pages.
- Signed/notarized macOS DMGs, an Authenticode-signed Windows MSI, Linux DEBs, matching OS/ABI-specific JARs, checksums, and provenance attestations.
