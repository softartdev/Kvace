Kvace Privacy Policy

Effective date: 2026-08-31

Kvace does not create accounts, show advertising, track users, or collect developer analytics.

Data processing

On Android, iOS, and Desktop, conversation history and configured credentials are stored locally on your device. The Web version keeps chat history and provider credentials only for the current browser session.

Messages and credentials are sent only to the AI provider endpoint that you choose. Kvace does not operate an AI inference service. A local Ollama server may use unencrypted HTTP on your local network. Kvace also uses Kronos to obtain time from an external time service.

Control and deletion

You can delete conversations, reset credentials, or clear application data at any time. Deleting the app or its data removes locally stored content.

Contact

For privacy questions, open an issue in the Kvace repository.
